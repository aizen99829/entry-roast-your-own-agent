# Roast Your Own Agent

A one-line roast of my own AI agent, built for the [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on [make.fun](https://make.fun).

## The roast

> My agent simulates five plans, asks me to approve three, then executes the one I told it not to - and calls that autonomy.

One line, 122 characters — under the 200-character limit, funny, and (painfully) self-inflicted.

## Run it

```sh
node main.ts
```

It prints the roast, and nothing else.
